# Module 3, bản hoàn chỉnh

`ket-qua/`: JSON của 10 đơn hàng tuần 46, đúng dạng script đọc đơn của Module 3 xuất ra. Bản này dựng bằng
`scripts/tao_du_lieu.py` để làm Module 4 trước khi có API key; script đọc đơn soạn cùng bài của Module 3.

Mỗi file một đơn: `so_don_khach`, `ma_khach`, `nguon` (file fax hay email), `ngay_dat`, `ngay_giao` (yyyy-mm-dd), `dong`
(mỗi dòng `ma_hang`, `so_luong`, `don_vi`), `can_nguoi_xem` và `ly_do` khi đọc chưa chắc.

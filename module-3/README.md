# Module 3: Gọi Claude bằng API

Script Python đọc đơn hàng fax và email trong du-lieu/don-hang-moi/ thành JSON đúng cấu trúc, rồi so với đơn đã nhập tay. Cần API key của Claude API.

- `bat-dau/`: chỗ học viên bắt đầu làm theo bài.
- `hoan-chinh/`: lời giải chạy được để so với bài của mình.

`requirements.txt` của module gồm SDK Python của Anthropic (`anthropic`) và `python-dotenv`. API key đặt trong `.env` ở
gốc repo, chép từ `.env.example`. Script của từng bài soạn cùng bài học của module trên Anthropic Exam Pro.

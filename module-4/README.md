# Module 4: Claude Code

Dùng Claude Code trên code cũ của khách: đọc hiểu công cụ nhập đơn viết năm 2016, viết test trước khi sửa, sửa lỗi số lượng, thêm chức năng nhập JSON đơn hàng của Module 3, và hook chặn ghi vào CSDL thật. Chỉ cần gói Claude có Claude Code.

- `bat-dau/`: chỗ học viên bắt đầu làm theo bài.
- `hoan-chinh/`: lời giải chạy được để so với bài của mình.

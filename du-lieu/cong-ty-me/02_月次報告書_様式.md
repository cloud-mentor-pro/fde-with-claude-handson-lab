# 海外子会社 月次報告書 様式

提出先：海外事業部（鈴木）　提出期限：翌月第3営業日 17:00（日本時間）
形式：本様式に沿って日本語で作成し、Excel の実績表を添付すること。

## 1. 生産実績

- 生産数量（品番別、計画比）
- 設備稼働率（成形機・ハーネスライン別）

## 2. 品質

- 工程内不良率（目標：1.0%以下）と主な不良項目
- 顧客クレーム件数と内容、対策状況

## 3. 課題と対策

課題ごとに「現状 → 原因 → 対策 → 期限 → 担当」の順に記載する。

## 4. 来月の計画

- 生産計画、主要な受注見込み
- 本社への依頼事項

## 記入上の注意

- 数値は必ず根拠となる実績表と一致させること。
- 「頑張ります」などの抽象的な表現は避け、具体的な数値と期限を書くこと。
